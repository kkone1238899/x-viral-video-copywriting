### AI UGC 视频 Prompt 库（cliprise/awesome-ai-ugc-video-prompts）

**核心提炼**
- 解决什么问题：AI 拍不出"像真人"的带货视频——手持感、口播话术、测评开箱怎么写 prompt，这个库按场景拆好模板，还附 FTC 合规和虚假证言避坑提示。
- 核心用法（4 步）：1) 按场景选模板（hook→body→close、开箱/测评/讲解等）；2) 填入产品名、卖点、时长等变量；3) 生成 UGC 风格 prompt，丢进 AI 视频工具出片；4) 换话术变量做 A/B 测款。
- 什么时候用 / 常见坑：做 TikTok/Reels 带货广告、请真人模特太贵时；坑：AI 假证言会违规（FTC 要求披露），别让 AI 模特说"我用了三个月"这类编造体验的话。

**适用场景**：做 DTC 电商、APP 推广、美妆/快消带货的营销团队和独立站卖家。

**怎么用它搞钱**：UGC 广告代投 / 带货——给品牌接 UGC 风格广告片代制按条收费，或给自己带货矩阵批量出广告素材。

### 100 个短视频钩子公式（rediumvex/viral-hooks-skill）

**核心提炼**
- 解决什么问题：视频前 3 秒没钩子就被划走——100 个按心理学分类的钩子公式，直接套自己的脚本生成 3 个备选钩子。
- 核心用法（4 步）：1) 把 skill 装到 `.claude/skills`（git clone 即可）；2) 粘一段脚本或只给主题；3) 让它从 10 类心理触发器（好奇缺口、反常识、故事、自白等）里挑选；4) 每次给 3 个钩子变体并标注适合平台。
- 什么时候用 / 常见坑：脚本已写好但开头平淡、完播率上不去时；坑：3 个钩子别选同一类别，最佳组合是截停型（否定/数据/提问）+ 留人型（故事/自白）。

**适用场景**：Reels/TikTok/Shorts 创作者、短视频代运营、任何要做高完播率内容的人。

**怎么用它搞钱**：短视频钩子代写/代运营服务；给客户账号批量优化旧视频开头，按条收费。

### 个人 IP 文案心法：抄—超—钞（@wangzaimedia）

**核心提炼**
- 解决什么问题：个人 IP 不知道从哪下手做内容和文案——给一套"抄→超→钞"三段心法：先抄爆款快速入门，再刻意练习超越，最后构建变现闭环。
- 核心用法（5 步）：1) 抄选题：研究 10 万+/100 万+ 爆款话题（职场焦虑、副业变现、个人成长、情感困惑等）；2) 抄标题：四公式（数字+身份+结果 / 否定常识+制造冲突 / 痛点+解决方案 / 时间紧迫感）；3) 抄结构：拆 100 篇爆款的文案结构（如 Dan Koe 式），用自己的亲身经历和独特视角"借题发挥"重写；4) 超：刻意练习一次只练一个点（标题 / 3 秒开头 / 钩子 / 转化），用点击率、评论、转化率数据复盘建立反馈机制；5) 钞：设计转化路径（免费→低价→中价→高价），变现核心是信任（持续输出价值、展示真实案例、长期主义）。
- 什么时候用 / 常见坑：个人 IP 冷启动、文案没章法时；坑：低水平重复不算努力，一次只练一个点；实测案例：同一咖啡馆话题，自我表达式标题阅读量 23，明确人群+痛点+解决方案式标题阅读量 8000+。

**适用场景**：做个人 IP、知识付费、副业内容号的创作者。

**怎么用它搞钱**：IP 陪跑 / 代运营服务——按"抄超钞"流程给客户做选题+文案+变现设计，按月收费；自己跑通后可转教学。

### TikTok 爆款广告 3 个反直觉素材公式（@free1342280）

**核心提炼**
- 解决什么问题：TikTok 带货素材像硬广、没人看完——三个反直觉公式让素材"看起来不像广告"。
- 核心用法（3 公式）：1) 反常识钩子开场：不用自夸式介绍，用"高价踩坑被低价打脸"的反差故事开场，0.5 秒内制造疑问，完播率可达普通开场的 2–3 倍，完播率决定算法放量；2) 失败场景＞成功场景：拍用错产品的尴尬、踩坑经历、买回来落灰，不拍用前用后对比——用户刷 TikTok 是找共鸣不是被教育，"我也犯过这个错"比"你应该买这个"好卖；3) UGC 保持"70% 假、30% 真"：纯真实卖不动货，30% 是广告主的转化设计但绝不能露馅，露馅即"广告感"，用户 1 秒划走。
- 什么时候用 / 常见坑：做 TikTok / 抖音带货广告、UGC 素材时；坑：素材生命周期只有 3–7 天，一天至少产出 5–10 条才能稳定测试——素材生产成本才是真正的成本，达不到这个产量的团队谈 ROAS 是空谈。

**适用场景**：TikTok / 抖音带货卖家、广告代投团队、UGC 素材工作室。

**怎么用它搞钱**：UGC 广告素材代制——按三公式批量生产素材，按条或按测试包收费；广告代投（素材能力是 ROAS 的前提）。

### $3M TikTok Shop 的 10 个 ChatGPT 带货 Prompt（@thetiktokwiz）

**核心提炼**
- 解决什么问题：TikTok Shop 带货全流程 prompt 拼不齐——10 条即拿即用的 ChatGPT prompt，覆盖店名→设计发散→人群→listing 文案→广告测算→违规申诉全链路。
- 总纲（最重要的一条）：绝不让 ChatGPT 从零发挥创意——每条 prompt 都先喂给它"已经跑通的东西"（已验证的 format + 清晰客户画像 + 真实产品 + 好参考）。
- 核心用法（6 步）：1) 店铺命名 prompt：批量生成宽泛品类店名（首字母缩写 4+ 字母、干净好记），快速筛出可用名；2) 爆款发散 prompt：把 ChatGPT 设定为"病毒式幽默 POD 服装营销策略师"，围绕已验证的爆款设计批量发散 50 个；3) 人群扩展 prompt：顺手要 20 个面向第二人群（如 Gen X）的短语，一次覆盖多人群；4) 风格对齐 prompt：要 10 个"简单、有力、反讽、boss energy"同类思路，写给真正买单的人；5) 迭代 prompt：对"差一点就爆"的创意像对待同事一样反复追问，把半成品推过终点；复用 prompt：喂给它"已经卖爆的概念"，基于成功案例再出新点子；6) 盈亏测算 prompt：把 ChatGPT 设为电商分析师，输入售价/成本/平台佣金/达人佣金，算出盈亏平衡 ROAS 和健康目标区间（示例数字：售价 23.99、成本 7.26、8% 平台佣金、20% 达人佣金 → 盈亏平衡 2.4）。
- 什么时候用 / 常见坑：TikTok Shop 起店、广告投放前测算、违规申诉时；坑：盈亏平衡 ROAS 只是及格线，测算出的"健康目标"才值得加预算；产品 P 到 AI 模特出视频时逐字检查字母拼写。

**适用场景**：TikTok Shop 卖家、POD（按需印制）服饰带货团队、跨境电商代运营。

**怎么用它搞钱**：TikTok Shop 代运营——按这 10 条 prompt 搭起号全流程，按店/按月收费；带货矩阵批量产设计+文案，规模即利润。

### $200k AI UGC 获客 Playbook（@BrianFrydberg）

**核心提炼**
- 解决什么问题：APP 获客做 faceless 内容缺"人格"、爆款不可复制——完整 AI UGC 方法论：3 种可规模化 format + "一胜百"拆解法 + 数据迭代规则 + 矩阵号搭建。
- 核心用法（6 步）：1) 评判视频只看三件事：是否停留、是否理解产品、是否执行 CTA——播放量不等于转化；2) 开拍前先回答三个问题：看完用户去哪、必须理解什么、用户已在解决什么问题；3) 三种可规模化 format：AI slideshows（Pinterest 建图库喂 LLM，最便宜易放大）、AI UGC creators（talking-head 全 AI 工作流：脚本→AI 人物→成片→配音→剪辑，全链可 agent 自动化）、AI cartoon influencers（最少人做、正在起量）；4) "一胜百"拆解法：不逐字抄爆款，按"前 3 秒发生了什么/产品何时出现/说话时在干嘛/hook 引入什么痛点/CTA 前产品做了什么"拆解，再换 hook/人物/房间/痛点/语言做 20–50 个单变量测试，并建一个可复用 prompt，输入获胜视频批量输出新 hook/脚本/场景；5) 数据迭代规则：同一 hook 在 3 个创作者都有效就继续推；产品出现前流失就提前露产品；6) 矩阵搭建：先 2–3 号验证 format 再放大（2–5 部手机+独立代理、n8n 定时发布、10–50 个号）。
- 什么时候用 / 常见坑：APP/产品用 AI 内容规模化获客、UGC 素材产能不够时；坑：别盯播放量虚荣指标，只盯停留/理解/CTA 三件事；平台要求标注 AI 生成，不编造证言。

**适用场景**：APP 推广团队、效果广告代投、做矩阵号获客的独立开发者/小团队。

**怎么用它搞钱**：AI UGC 代制 / 效果投放代运营——按 playbook 建一条"拆解→复写→测试→放大"流水线，按素材条数或广告消耗提点收费；自己跑 APP 时获客成本可压缩到人工团队的零头。

- 核心用法（5 步）：1) 找买家：让 AI 扮演该产品的客户调研员，列出 5 类买家画像、每类想解决的痛点，以及他们在网上吐槽时会用的原话；2) 淘汰弱产品：让 AI 按利润空间、解决的问题、在 10 秒视频中展示的难易度给候选产品打分，砍掉后半段并解释原因；3) 重写产品页：针对某一类买家重写产品描述——痛点开头、用词直白、3 个具体好处、诚实回应 1 个反对意见，不吹牛；4) 写广告脚本：一次写 5 条短 UGC 风格视频脚本，每条含 3 秒钩子 + 1 个痛点 + 1 个产品演示瞬间 + 明确行动召唤；5) 追踪每次测试：让 AI 建一张测试追踪表（产品/角度/脚本/花费/点击/成交/下一步动作），花费达到设定的阈值时提示砍掉还是保留。

### 88 天长青广告钩子拆解："品类刻板印象切割法"（@TommyGuera）
